Frequently Asked Questions

How do I start using Aurix?

Use the /start command in a Discord server where Aurix is active. This creates your bot profile and starts tracking virtual progression.

Can I use Aurix on my own server?

Yes. Use the Add Bot to Your Server button and authorize Aurix for your server.

What happens when I rank up?

Higher ranks can unlock badges, profile status, cosmetics, and identity perks. These are virtual bot features only and have no cash value.

Is Aurix free to use?

Yes, Aurix has free core features. Premium adds cosmetics, profile status, convenience, reminders, and modest capped boosts without paid PvP dominance.

How can I report bugs or suggest features?

Join the official Discord server and use the suggestions or bug-report channels.
