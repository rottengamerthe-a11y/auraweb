❓ Frequently Asked Questions

How do I start using Aurix?

Use the /start command in a Discord server where Aurix is active. This creates your bot profile and starts tracking virtual progression.

Can I use Aurix on my own server?

Yes! Click the "Add Bot to Your Server" button and authorize Aurix. You'll have full access to all features.

What happens when I rank up?

Higher ranks can unlock in-bot badges, profile status, and progression modifiers. These are virtual bot features only and have no cash value.

Is Aurix free to use?

Yes, Aurix has free core features. Premium plans add enhanced command settings, virtual progression modifiers, higher premium effect caps, premium-only shop items, profile cosmetics, extra reminder slots, profile membership status, and a premium activation announcement for users who want more bot features.

How can I report bugs or suggest features?

Join our official Discord server and use the #suggestions and #bug-reports channels. We read and respond to all feedback!
